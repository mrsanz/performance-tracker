# Performance Tracker

A full-stack application template for tracking performance events with a Bun + Fastify backend, SQLite + Drizzle ORM, and a React + Vite frontend. The project follows a strict constitution (architecture and quality gates) and ships with CI/CD, Docker, and Helm scaffolding.

## Quick Start

For end-to-end setup steps, see the feature quickstart:

- specs/001-project-setup-database/quickstart.md

## Install

```bash
bun install
```

## Scripts

- Run backend during development (see tasks to wire dev scripts):
	```bash
	bun run index.ts
	```
- Run tests:
	```bash
	bun test
	```

## Notes

This project was created using `bun init` in bun v1.2.23. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
